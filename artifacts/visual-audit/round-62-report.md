# Round 62 · 建筑—自然地形复合验收

## 本轮目标

把“深水城河道水城”从“河道 + 小方块建筑”升级为真正的父级水域与城市规划叠加：

- 河道、支流、石桥、木桥和水上市集保持由地形生成器负责；
- 城市道路、街区、地块和独立建筑重新叠加到可建岸线；
- 地标建筑获得独立内部 LOD；
- 陌生的“盐沼水闸天文学院村镇”不能被学院子词抢成单体学校。

## 修复内容

1. 水城地块扩大占地和建筑覆盖率，并扩展两岸街区分布范围。
2. 水城不再把 `river` 父级误当作纯自然场景，恢复规划道路、街区面、地块院落和开放空间。
3. 聚落建筑入口路线使用“地块入口 → 门厅 → 前门”的路线；旧野外独立建筑保留原有外部转角路线。
4. 增加“村镇”父级识别，避免“学院村镇”退回学校单体。
5. 增加潮汐沟渠、水闸、盐沼等可组合水城语义。
6. 盐沼水城的实际河面、桥、岸线和市场码头增加湿地、栈道和架高木桥几何标签。
7. 地下档案模块落实 `reserve-vault` 几何语义。

## 仍未通过

- 水城低角度总览仍然偏远，城市垂直体量需要下一轮相机和地标层级优化；
- 普通住宅的按需内部仍比独立专用建筑简单；
- 聚落内部相机当前仍偏远，下一轮需要增加“建筑聚焦”自动取景，才能更清楚检查家具和门洞；
- 水城神殿和巡逻塔需要更强的外部地标几何（钟塔、连续码头棚、屋顶连桥）；
- 城市外围仍有可见空地，下一轮需要按密度和规模把“空地、农地、码头后场”做成有用途的空间，而不是纯空白。
