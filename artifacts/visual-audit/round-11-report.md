# Round 11 分层场地生成与视觉审计

日期：2026-08-08  
基线：`62e4d5e feat: render pitched architectural roof massing`

## 本轮结论

本轮建立了 `SceneProgram → SiteProgram → District/Road/Parcel → BuildingInstance → BuildingProgram → Geometry` 的分层组合链。城市、村庄和野外建筑不再共用一个“撒方块”入口：城市使用道路层级、功能区和沿街地块；村庄围绕自然/公共锚点有机生长；野外先保留自然地形，再寻找建筑垫层并调用独立建筑模块。

12 个强制提示的当前确定性矩阵全部通过自动校验，分数均为 100。浏览器实测保持约 60–61 FPS。仍未达到成品级的部分主要是：远景建筑立面细节有限、COC 海滨小镇与奇幻港区的城市轮廓仍相似、浮空岛还是阶梯式玄武岩台地而非更有机的破碎岛体、单层视图尚未自动聚焦核心建筑、`SceneRenderer` 产物仍有 557.59 kB 的构建警告。

## 架构改动

- `src/site-program/schema.ts`：定义场地边界、地形、水系、功能区、道路、地块、开放空间、战术区、建筑实例和 LOD 策略。
- `src/site-program/planner.ts`：根据提示、规模、密度和 Seed 规划城市/村庄/港区/工业区/矿业聚落等场地。
- `src/generators/siteSettlement.ts`：把 SiteProgram 落实为道路、水域、地块、建筑、桥、码头、高架铁路、洪水高脚结构、山地台地、工业设施和浮空高度带。
- `src/generators/buildingModule.ts`：地块独立调用建筑模块；核心建筑生成真实 1F、上层、B1、墙、楼板、楼梯、房间、家具和路线；邻近与远景使用 facade/mass LOD。
- `src/generators/wilderness.ts`：森林木屋/炼金小屋保持森林地形，由组合层增加地基、门廊、水井、围栏、柴堆、外部道路和逃生路线。
- `src/scene-program/localPlanner.ts`：父场地拥有子建筑语义；城市医院仍是单体建筑，港区/市场村/山地聚落/道路驿站不会被子建筑词抢走领域。
- `src/workers/GenerationClient.ts`：Worker/Ollama 10 秒无响应或 Worker 崩溃时自动回退到确定性本地生成，避免按钮永久卡住。

## 准确的剩余工作

1. 单层/B1/屋顶视图应按当前层内容自动重算相机包围盒，而不是继续框住整个城镇。
2. facade/mass LOD 需要更多窗、门廊、烟囱、招牌、工业桁架和时代化立面语言。
3. COC 港镇需要独立于奇幻港区的街廓、道路宽度、建筑材质和公共设施语法。
4. 浮空岛需要真正断开的有机轮廓、悬垂岩体和更明确的跨岛高度路线。
5. LOD 已保留稳定 Seed、入口、占地和层数，但 UI 尚没有“点击建筑提升到完整内部”的交互。
6. `SceneRenderer` 应继续拆包或按功能动态加载，消除 500 kB 构建警告。
