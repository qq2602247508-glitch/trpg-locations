# Regression 11：城镇建筑进入、地下层与返回聚落

日期：2026-08-12

## 本轮目标

真实验证第 5 条长期目标中的核心交互：

- 聚落中的完整内部建筑可以进入。
- facade/mass 建筑可以按需展开内部蓝图。
- 聚焦后可以切换 1F、上层和 B1。
- B1 保留真实几何、支撑、楼梯和 5 英尺网格。
- 返回聚落后恢复完整屋顶、城市上下文和原始渲染规模。

## 发现并修复的问题

### 1. 邻楼地下集群隐藏选中建筑

运河城中，完整内部 guild 的地下档案库拥有全局最大的 `focus-cluster`。聚焦相邻 facade tower 并切换 B1 时，渲染器仍使用 guild 的集群过滤所有批次，使 tower 的普通 cellar 蓝图变成空画布：

- 修复前：1 draw call，0 triangles。
- 修复后：6 draw calls，360 triangles。

修复方式：楼层 cluster 选择在建筑聚焦状态下只统计当前 `building-instance`；当前建筑没有专用 cluster 时不启用 cluster 隔离。

### 2. 高架聚落的按需地下楼梯过长且缺乏支撑

高架水城建筑的地面层高于世界地面，通用 cellar 原先用一根直梯承担约 29 英尺高差。修复为：

- 两段折返楼梯；
- 中间可站立平台；
- 两根从地下地坪到平台的结构支柱；
- 上下段各承担一半高差；
- 专业地下功能模块拥有自己的交通时，不再重复生成通用 cellar 与楼梯。
