# Project constraints

- Build this project from first principles. Do not read or reuse other local TRPG scene projects.
- One tactical grid cell is always 5 feet / 1.524 metres.
- Semantic models may classify intent, but deterministic code owns dimensions, topology and validation.
- Every generator must be seed-reproducible and must pass validation before delivery.
- Do not implement new categories as single fixed maps; use composable traits, distributions and rules.
- Performance and tactical usability are product requirements, not optional polish.
