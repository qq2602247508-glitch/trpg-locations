# TRPG Locations

面向桌面跑团的程序化 3D 场景生成器。每个战术格固定为 5 英尺，场景由带种子的空间规则生成，而不是固定地图换皮。

当前首个垂直切片覆盖：

- 酒馆：公共大厅、后勤空间、客房层与垂直交通
- 塔楼：多层垂直战斗、环形或方形轮廓、屋顶平台
- 下水道：主渠、支渠、检修道、水流与竖井
- 洞窟：洞室网络、高低差、岩台和危险区
- 专用建筑语法：教堂、神殿、庄园、兵营、图书馆、工坊、仓库、堡垒、矿井
- 城镇/城市/港区规划：弯折道路图、密度传播、功能区关系、城墙门户、市民/货运人流、碰撞约束地块、独立建筑模块和水岸路线
- 聚落建筑实例：住宅、酒馆、神殿、仓库、塔楼、庄园各自使用独立体量语法，并记录可复现的建筑 Seed、楼层数、逐层层高和占地；大型地图先显示外部代理，战斗靠近时可按实例展开室内
- 城市时段层：白昼市场/通勤路线、全天服务路线和夜间城墙巡逻路线可独立显示，光照与雾色同步切换
- 自然与特殊战术空间：河谷、裂谷、山地、冰原、遗迹、地下湖、森林和沼泽；河道、干河床、火山口、墓丘/墓穴、林冠和菌林作为可组合地貌/覆盖算子改变底层高程与路线，不只增加主题道具
- 战术视图：建筑可切换半透明剖切，直接观察墙体、楼板、房间和内部战斗关系；自然地形网格按每块台地/冰 shelf 的实际高度贴合，不再只覆盖一张平面
- 楼梯与坡道也有贴面网格：网格沿每个踏步的实际高度和朝向绘制，和台地一样属于可行走表面的一部分
- 自适应输入：无法精确识别时按空间特征组合降级，不中止生成

## 本地运行

```bash
npm install
npm run dev
```

固定地址：`http://127.0.0.1:5241/`

## 验证

```bash
npm run check
npm run build
```

生成器输出房间、路线、战术特征、几何模块与诊断报告。Three.js 只负责表现这些结果，因此规则层可以批量测试而无需启动浏览器。

右侧“导出场景 JSON”会保存当前完整 `GeneratedScene`（包括 Seed、5 英尺格尺寸、建筑实例清单、路线时段和诊断），可作为复现、分享与后续室内展开的存档。

浏览器中的规划与几何校验在 Web Worker 执行；Three.js 渲染核心延迟加载。当 Worker 不可用时，会按需加载同一确定性生成器作为回退。

对本地分类器确实不认识的题材，worker 可选请求 `http://127.0.0.1:11434` 上的 `qwen3.6:35b-mlx`。模型只能返回枚举化的环境、拓扑偏好、高差、水体、光照、掩体、主题和短地标/危险词。超时、服务不可用或返回不合规都立即回退，不影响一键生成。
