# TRPG Locations

面向桌面跑团的程序化 3D 场景生成器。每个战术格固定为 5 英尺，场景由带种子的空间规则生成，而不是固定地图换皮。

当前首个垂直切片覆盖：

- 酒馆：公共大厅、后勤空间、客房层与垂直交通
- 塔楼：多层垂直战斗、环形或方形轮廓、屋顶平台
- 下水道：主渠、支渠、检修道、水流与竖井
- 洞窟：洞室网络、高低差、岩台和危险区
- 专用建筑语法：教堂、神殿、庄园、兵营、图书馆、工坊、仓库
- 城镇/城市/港区规划：道路骨架、中央广场、功能区、独立建筑模块和水岸路线
- 自适应输入：无法精确识别时按空间特征组合降级，不中止生成

## 本地运行

```bash
npm install
npm run dev
```

固定地址：`http://127.0.0.1:5241/`

## 验证

```bash
npm run check
npm run build
```

生成器输出房间、路线、战术特征、几何模块与诊断报告。Three.js 只负责表现这些结果，因此规则层可以批量测试而无需启动浏览器。
